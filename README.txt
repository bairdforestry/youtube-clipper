GET STARTED

1. Right-click the downloaded ZIP and choose Extract All.
2. Keep the extracted folder in a location you want to keep.
3. Open that folder and double-click YouTube Clipper.exe.
4. Click Desktop shortcut in the app for quick access next time.

Keep the runtime folder beside the application. Python, FFmpeg, the
YouTube download engine, a JavaScript runtime and the supporting libraries
are included. No separate dependency installation or administrator access
is required. Internet access and enough free disk space are needed.

ILLUSTRATED GUIDE

Open YouTube Clipper - User Guide.pdf for instructions with screenshots.
You can also click User guide (PDF) at the bottom of the app.

DOWNLOAD A VIDEO OR CLIP

1. Paste a YouTube link and click Analyze.
2. Choose Download the full video, or enter START and END times.
   For example, 3:03:46 to 3:03:56 saves ten seconds.
3. Choose Video + audio or Audio only, then choose an output format.
4. Choose your SAVE TO folder and click the Download button.
5. Click Open folder to find the finished file.

VIDEO FORMATS: MP4, MKV, WebM.
AUDIO FORMATS: MP3, M4A, FLAC, WAV, or the original best-available stream.

FIX VOICES THAT DISAPPEAR ON PHONES OR MONO SPEAKERS

Enable Fix stereo cancellation by using phase-safe dual mono.
This copies the first channel to both sides to prevent cancellation.
Leave it off for normal stereo. It cannot recover sound that is missing
from the first channel, remove background noise, or fix every audio issue.
Best available - original audio keeps the source unchanged and cannot
apply this repair.
