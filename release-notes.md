### Download and run

Download **YouTube-Clipper-Windows-x64.zip**, right-click it and select **Extract All**, then open the extracted folder and run **YouTube Clipper.exe**. Keep the `runtime` folder beside the application.

The ZIP includes all application dependencies and a four-page PDF guide with screenshots. Click **Desktop shortcut** in the app for quick access next time. No Python, FFmpeg or JavaScript runtime installation is needed.
